# Bedrock Addon Installer — сайт

Откройте `index.html` в браузере для локального просмотра. Сайт не требует сборки.

## Публикация

Загрузите содержимое этой папки на любой статический веб-хостинг, сохранив структуру каталогов. Установщик уже лежит в `download/BedrockAddonInstaller-Setup.exe`, поэтому все кнопки скачивания будут работать по относительной ссылке.

## Содержимое

- `index.html` — адаптивная страница на русском языке.
- `assets/` — иконка приложения и аватар Kwizeek.
- `download/` — Windows Setup установщик версии 1.0.0.
